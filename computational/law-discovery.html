Multi-Agent Framework for Physical-Law Discovery

An LLM-driven symbolic-regression framework in which cooperating agents propose, evaluate, refine, and interpret candidate analytical laws for materials properties. A beam search balances predictive accuracy against expression complexity, and a retrieval-augmented explanation agent grounds each discovered formula in the literature.

  • Symbolic regression
  • LLM agents
  • Beam search
  • GraphRAG / LightRAG
  • Interpretable ML

Overview

Six Stages

  1. i
    Literature & data
    Publications are indexed into a GraphRAG/LightRAG knowledge base; an agent recommends variables and admissible operators.
  2. ii
    Task prompt
    General instruction, task description, formula memory, and few-shot examples with a JSON schema (formula, theory).
  3. iii
    Beam-search setup
    Set maximum depth D, proposals per node N, and beam width K.
  4. iv
    Generate & score
    Agents propose, inspect, fit, and reflect; only the K lowest-scoring nodes advance.
  5. v
    Interpretation
    An explanation agent states physical meaning, assumptions, and limitations.
  6. vi
    Deployment
    The most accurate, interpretable laws are used for prediction and materials design.
